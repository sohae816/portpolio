# 과일 필드노트

마트·편의점·온라인몰을 관찰하며 기록을 쌓는 개인용 노트 웹앱입니다.
빌드 과정 없이 `index.html` 한 파일로 동작하는 정적 사이트예요.

## 구성
- **필드노트**: 하루 카드 → 템플릿(현장 체크리스트, 메모, 사진 여러 장, 트렌드, 데이터 분석, 가격 체크, 진열 관찰, 소싱 아이디어)
- **MD 기본 지식**: MD 용어, 숫자 감각 공식, 유통 구조, 채널별 관점, 내 용어장
- **먼슬리 리포트**: 월별 기록 내보내기 → 분석 결과 저장, 데이터 백업/복원

## 데이터 저장 방식
- 모든 기록은 **사용하는 브라우저의 localStorage**에만 저장됩니다. 서버로 전송되지 않아요.
- 그래서 기기·브라우저·주소(도메인)가 바뀌면 기록이 따로 쌓입니다.
- 옮길 때는 **먼슬리 리포트 탭 → 데이터 백업 / 복원**을 사용하세요. (백업 텍스트는 저장소에 커밋하지 마세요)
- 사진은 640px 폭으로 줄여 저장하지만, 브라우저 저장 용량(보통 5MB 안팎)이 있어서 사진이 많으면 가득 찰 수 있어요. 가끔 백업하고 정리하세요.

## GitHub Pages 배포
1. 새 저장소를 만들고 `index.html`, `README.md`를 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 *Deploy from a branch*, Branch를 `main` / `/ (root)`로 지정합니다.
3. 잠시 후 `https://<계정>.github.io/<저장소>/` 주소로 접속됩니다.
4. 폰에서는 이 주소를 열어 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

> 무료 플랜에서 GitHub Pages는 공개(public) 저장소에서만 쓸 수 있어요. 이 파일에는 개인 기록이 들어 있지 않지만, 기록 내용은 어디에도 올리지 마세요.

## Claude Code에 붙여넣을 요청 예시
```
이 폴더의 index.html을 GitHub Pages로 배포하고 싶어.
1) git init 후 첫 커밋
2) gh CLI로 public 저장소 생성(이름: portpolio) 및 push
3) GitHub Pages를 main 브랜치 root로 활성화
4) 배포 URL이 열리는지 확인해서 알려줘
```
